Политика конфиденциальности Mpmind: интеграция с Instagram

Редакция от 12.11.2026

О приложении и операторе

Mpmind-IG — интеграция с Instagram в приложении Mpmind сервиса mpmind.ru. Она помогает владельцам подключённых профессиональных аккаунтов работать с публикациями, статистикой, комментариями и сообщениями Instagram.

Оператор сервиса — индивидуальный предприниматель Кураев Альфред Викторович, ИНН 695014304322. Почтовый адрес: 129343, город Москва, проезд Серебрякова, д. 14, стр. 6, оф. 6105. Контакт по вопросам обработки и удаления данных: support@mpmind.ru.

Эта страница описывает обработку данных в интеграции с Instagram. Обработка данных регистрации и посещения сайта описана в общей политике MpMind.

Какие данные получает интеграция

После подключения аккаунта через Instagram и предоставления разрешений Mpmind-IG получает данные, которые доступны этому аккаунту через API Meta:

  • Идентификаторы аккаунта, имя пользователя, название, описание, изображение профиля, тип аккаунта и доступные показатели профиля.
  • Публикации, подписи, ссылки на изображения и видео, даты публикации и доступную статистику публикаций и аккаунта.
  • Комментарии и ответы: текст, идентификаторы, имена пользователей, время и состояние комментариев.
  • Диалоги Direct и сообщения: идентификаторы участников, доступные имена пользователей, текст, доступные вложения, время и статусы сообщений.
  • Токен доступа, предоставленные разрешения и сведения о сроке действия подключения.
  • События Instagram, необходимые для обновления комментариев, сообщений и их состояния, а также технические сведения об успешности синхронизации и ошибках.

Состав данных зависит от выданных разрешений, возможностей API Meta и используемых функций. Сервис не получает пароль Instagram.

Для чего используются данные

Данные используются для подключения аккаунта, синхронизации и отображения его материалов, ведения истории статистики, подготовки отчётов, обработки комментариев и сообщений, а также выполнения действий, выбранных пользователем в сервисе: публикации контента, ответов и модерации.

Токен используется для авторизованных запросов к API Meta и обновления подключения. Технические сведения нужны для работы очередей, предотвращения повторной обработки событий и диагностики ошибок.

Если пользователь запускает AI-разбор статистики или создание AI-черновика ответа, необходимые данные передаются подключённому поставщику AI: для разбора — данные публикаций и статистика; для черновика — сведения об аккаунте, подпись публикации, комментарий и примеры предыдущих ответов. Полученный результат показывается пользователю в сервисе.

Хранение и доступ

Загруженные данные и результаты обработки хранятся в инфраструктуре MpMind. Доступ в интерфейсе интеграции ограничен пользователями с соответствующими правами. Токены доступа хранятся в зашифрованном виде.

В работе интеграции участвуют Meta/Instagram как источник данных и получатель запросов к API, поставщики технической инфраструктуры, а при запуске AI-функций — подключённый поставщик AI. Передаваемые при этом данные зависят от выполняемой функции.

Данные хранятся в течение времени, необходимого для предоставления выбранных функций, и удаляются по обращению владельца или другого лица, имеющего право на соответствующий запрос. Если отдельные сведения необходимо сохранять по закону, при рассмотрении запроса оператор сообщает об этом заявителю.

Отключение доступа и удаление данных

Отключение аккаунта в MpMind очищает сохранённый токен и останавливает дальнейшую автоматическую синхронизацию. Ранее загруженные публикации, комментарии, сообщения и статистика при этом не удаляются автоматически.

Для отзыва разрешений со стороны Instagram удалите Mpmind-IG из списка активных приложений в настройках Instagram. Отзыв разрешений и удаление ранее сохранённых данных в MpMind — отдельные действия.

Чтобы запросить удаление данных из MpMind, напишите на support@mpmind.ru. Укажите имя Instagram-аккаунта и какие данные требуется удалить. Не присылайте пароли, токены, коды входа или резервные коды. Для защиты данных оператор может уточнить сведения, необходимые для проверки права на запрос.

Подробный порядок обращения приведён на странице «Удаление данных Instagram из MpMind».
